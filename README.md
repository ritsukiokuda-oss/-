# ドット・ランナー

オリジナルのドット絵キャラクターを操作して遊ぶ、ブラウザ用の2D横スクロールアクションです。
HTML / CSS / JavaScript だけで作っていて、ライブラリもビルドも不要です。

## 遊び方

`index.html` をブラウザで開くだけで動きます。

| 操作 | キーボード | スマホ |
| --- | --- | --- |
| 左右に移動 | ← → / A D | ◀ ▶ ボタン |
| ジャンプ | Space / ↑ / W / Z（長押しで高く跳ぶ） | JUMP ボタン |
| リスタート | R | ゴール後に JUMP |

コインを集めながら、右端のゴールの旗を目指してください。穴に落ちるとスタート地点に戻ります。

## ファイル構成

- `index.html` … 画面のレイアウト
- `style.css` … 見た目（キャンバスは `image-rendering: pixelated` でドットをくっきり拡大）
- `js/sprites.js` … キャラクターのドット絵データ（12×16ピクセル、文字列で1ピクセルずつ定義）とパレット
- `js/main.js` … 入力、物理（重力・当たり判定）、ステージ、カメラ、描画

## カスタマイズ

- **キャラの見た目**: `js/sprites.js` の `PALETTE` の色や、`HEAD` / `LEGS` などの文字列を書き換えると変わります。
- **動きの調整**: `js/main.js` 冒頭の `MAX_SPEED`、`JUMP_V`、`GRAVITY` などの定数を変えてください。
- **ステージ**: `buildLevel()` の穴（`gaps`）や足場（`platforms`）の座標を編集します。
