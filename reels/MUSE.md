# Muse への引き継ぎガイド

Muse（Muse from Meta）には **ネタ担当** と **分析担当（振り返り）**、それに **毎日の段取り** を任せます。
動画の生成（Kling）と品質チェック（Claude）は、これまで通りプログラムが自動で行います。

| 担当 | 担い手 | やり取り |
| --- | --- | --- |
| ネタ担当 | **Muse** | Muse が決まった書式でネタを出す → プログラムに貼って取り込む |
| 制作担当 | Kling（自動） | 変更なし |
| チェック担当 | Claude（自動） | 変更なし。よくある失敗は次の引き継ぎ文で Muse に伝わる |
| 分析担当 | **Muse** | プログラムが出す数字の表を Muse に貼って振り返ってもらう |
| 段取り・リマインド | **Muse** | 投稿日、承認待ち、振り返りの日を Muse に管理してもらう |

## 最初に1回だけ Muse に渡すもの

1. **引き継ぎ文**: `python -m reelbot muse-brief` を実行すると表示されます（`data/muse_brief.md` にも保存されます）。中身は次のとおりです。
   - 役割（ネタ出しと振り返り）
   - ネタのルール（あるある×人間っぽい動き、1カット完結、禁止事項）
   - **出力の書式**（プログラムが読み取るために必要です）
   - これまでに出したネタ、チェックで多かった失敗、投稿の数字
2. **アカウントの情報**（引き継ぎ文に加えて、あなたが書き足してください）
   - アカウント名と、想定している見る人（例: 20〜40代の会社員、猫好き）
   - 投稿の頻度（例: 毎日1本、19時）
   - 参考にしているアカウントや動画（真似するのではなく、雰囲気を伝える目的で）
3. **Muse の設定**
   - 設定から「Meta の AI 改善への利用」を **オフ** にする（初期状態はオン）
   - Instagram 連携をオンにすると、アカウントの投稿を見ながら相談できます

最初のメッセージの例:
> これから Instagram リールのネタ担当と分析担当をお願いします。下の引き継ぎ文を覚えておいてください。（引き継ぎ文を貼る）

## 毎回のやり取り

### ネタ出し（例: 週に1回）
1. `python -m reelbot muse-brief` で最新の引き継ぎ文を作り、Muse に貼る（過去のネタや失敗が更新されているため）
2. Muse に「書式どおりにネタを5個ください」と頼む
3. Muse の回答をコピーして取り込む
   ```bash
   python -m reelbot ideas --paste      # 貼り付けて Ctrl+D（Windows は Ctrl+Z → Enter）
   # または、回答をテキストファイルに保存して
   python -m reelbot ideas --file muse.txt
   ```
4. `python -m reelbot produce -n 5` で、Kling による制作と自動チェックが進みます

### 振り返り（例: 投稿の3日後や週末）
1. `python -m reelbot analyze --for-muse` で投稿の数字の表を出す
2. 表を Muse に貼り、「次のネタに活かせる学びを3〜5行で」と頼む
3. Muse の回答を保存しておく（次の引き継ぎ文や、Claude にネタを出させる時にも使われます）
   ```bash
   python -m reelbot learnings          # 貼り付けて Ctrl+D
   ```
   Muse が Instagram 連携で直接数字を読める場合は、1. を飛ばして Muse に直接聞いても構いません。

### 段取り（Muse にお願いしておくと便利なこと）
- 「毎朝9時に、承認待ちのリールがあるか確認するよう声をかけて」
- 「毎週金曜に、今週のリールの振り返りをリマインドして」
- 「投稿予定日をカレンダーに入れて」

## うまく取り込めない時
- Muse の回答に「タイトル:」「英語プロンプト:」の行があるか確認してください。**英語プロンプトが無いネタは取り込めません**。
- 書式が崩れていたら、Muse に「引き継ぎ文の書式どおりに出し直して」と頼んでください。
- JSON 形式で返ってきた場合も、そのまま取り込めます。
