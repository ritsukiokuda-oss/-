# 訪問フォロー自動化（名刺・エイト → Googleチャット通知 ＋ お礼メール下書き）

## できること

1. 訪問先で名刺をスマホで撮り、Googleドライブの **「名刺_受信」** フォルダに入れる
2. 10分以内に自動で読み取り、Googleチャットに通知（会社名・部署・役職・氏名・住所）
3. Googleカレンダーの訪問予定が終わったら、**お礼メールを Gmail の下書きに作成**（送信はしません）
4. 毎日18時に **「本日のハガキ宛先」** をGoogleチャットにまとめて通知（名刺が未登録の訪問も教えてくれます）
5. すべての記録がスプレッドシート **「訪問ログ」** に残る（ハガキを書いたらチェックを付けられます）

```
📮 本日のハガキ宛先（2件） 2026/11/25

1. 株式会社サンプル商事　営業部 部長
　 山田 太郎 様
　 〒100-0001 東京都千代田区千代田1-1-1 サンプルビル5F
```

## 設定手順（15分くらい）

### 1. Googleチャットの通知先（Webhook）を作る
1. Googleチャットで通知用のスペースを作る（例：「訪問フォロー」。自分1人のスペースでOK）
2. スペース名の横の ▼ →「アプリと統合」→「Webhook を追加」
3. 名前に「訪問フォロー」と入れて保存し、表示された **URLをコピー**

※ メニューが出ない場合は、会社のGoogle Workspace管理者がWebhookを制限しています。管理者に許可を依頼してください。

### 2.（なし）APIキーは不要です
名刺はGoogleドライブの文字認識（OCR）で読み取ります。費用はかかりません。
読み間違いがあったときは「訪問ログ」を直接直してください。メールアドレスが読めなかった名刺も、訪問ログの「メール」欄に手入力すれば10分以内に下書きが作られます。
読み取り精度を上げたくなったら、ClaudeのAPIキー（console.anthropic.com で発行）をスクリプトプロパティ `ANTHROPIC_API_KEY` に登録するだけで切り替わります。

### 3. Apps Script にコードを貼る
1. https://script.google.com →「新しいプロジェクト」→ 名前を「訪問フォロー」に変更
2. 左の ⚙「プロジェクトの設定」→「appsscript.json マニフェスト ファイルをエディタで表示する」にチェック
3. エディタに戻り、`コード.gs` の中身を全部消して [`Code.gs`](./Code.gs) の内容を貼る
4. `appsscript.json` の中身を [`appsscript.json`](./appsscript.json) の内容に置き換える
5. 保存（Ctrl+S）。自社名・名前・署名は入力済みです

### 4. URLとキーを登録する
⚙「プロジェクトの設定」→ 一番下の「スクリプト プロパティ」→「プロパティを追加」

| プロパティ | 値 |
| --- | --- |
| `CHAT_WEBHOOK_URL` | 手順1でコピーしたURL |

### 5. 初期設定を実行する
1. エディタ上部の関数選択で **`setup`** を選び「実行」
2. 権限の確認が出たら自分のアカウントで許可（「このアプリは確認されていません」と出たら「詳細」→「安全ではないページに移動」）
3. 実行ログに「名刺を入れるフォルダ」「訪問ログ」のURLが出ればOK
4. **`testNotify`** を実行して、Googleチャットにテスト投稿が届くか確認

## 毎日の使い方

- **名刺を撮る**：スマホのGoogleドライブアプリで「名刺_受信」フォルダを開き、＋ →「カメラ」または「スキャン」。フォルダをスター付きにしておくとすぐ開けます。1枚の写真には名刺を1枚だけ写してください。
- **カレンダー**：予定名に会社名を入れておくと（例：「サンプル商事 訪問」）、名刺と予定が確実に紐づき、予定の終了時刻にお礼メールの下書きができます。紐づかない場合は名刺の読み取り直後に下書きを作ります。
- **お礼メール**：Gmailの「下書き」を開き、内容を確認・追記して送信。
- **ハガキ**：18時の通知か「訪問ログ」を見て書き、書いたら「ハガキ」列にチェック。

## エイト（プレミアム）のCSVから取り込む

エイトで撮った名刺も取り込めます。エイトは人の手で入力・確認してくれるので、データが正確です。

1. いつもどおりエイトで名刺を撮る（データ化されるまで待つ）
2. パソコンでエイトを開き、名刺データをCSVでダウンロードする
3. ダウンロードしたCSVを、ドライブの **「エイト取込」** フォルダに入れる（ファイル名はそのままでOK）
4. 10分以内に、**新しく増えた名刺だけ** チャットに通知され、お礼メールの下書きができ、ハガキ宛先リストに入ります

- **初回**：過去の名刺がまとめて通知されないよう、今日交換した名刺だけを通知し、それ以外は「取り込み済み」として覚えます
- **2回目以降**：前回までに取り込んでいない名刺のうち、名刺交換日が14日以内のものを通知します（日数は `CONFIG.EIGHT_RECENT_DAYS`）
- **写真でも登録していた名刺**：同じ人（メールアドレスか会社名＋氏名が同じ）なら、新しい行は作らず、エイトのデータで訪問ログを正確な内容に直します
- エイトから書き出すとき、全件でも期間を絞っても大丈夫です（取り込み済みの名刺は自動で飛ばします）
- 「エイト取込」フォルダは、`setup` を実行すると作られます。前に `setup` を実行済みの場合も、もう一度実行してください

## 読み取りのコツ（写真・APIキーなしの場合）

- 名刺を画面いっぱいに、まっすぐ・明るい場所で撮る（「スキャン」機能がいちばん確実です）
- 1枚の写真に名刺は1枚だけ（APIキーなしでは複数枚を分けられません）
- 縦書きや、デザインが凝った名刺は読み間違えやすいので、通知を見て「訪問ログ」を直してください

## 細かい調整

| 変えたいこと | 場所 |
| --- | --- |
| お礼メールの文面 | `Code.gs` の `MAIL_SUBJECT` / `MAIL_BODY` |
| まとめ通知の時刻 | `CONFIG.SUMMARY_HOUR` を変えて `setup` を再実行 |
| 「訪問」とみなす予定 | `CONFIG.VISIT_KEYWORDS`（予定名にこの言葉があるか、場所が入っている予定） |

## うまくいかないとき

- **「⚠️ 名刺を読み取れませんでした」と通知が来た**：ファイル名の先頭に `[読取エラー]` が付いてフォルダに残ります。撮り直して入れ直すか、訪問ログに手入力してください。
- **通知が来ない**：Apps Script 左の「実行数」でエラーを確認。`CHAT_WEBHOOK_URL` が正しいか確認し、`testNotify` を実行。
- **「⚠️ エイトのCSVを取り込めませんでした」と通知が来た**：通知に出ている見出し名を開発担当に伝えてください（エイトのCSVの形式が変わった可能性があります）。
- **下書きができない**：メールアドレスが読めなかった場合は作られません（通知に「メールなし」と出ます）。訪問ログの「メール」欄に入力すれば作られます。
